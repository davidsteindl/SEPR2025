# TicketLine Web Application

Fullstack ticket booking system developed by a team of 6 students as part of a university Software Engineering course.

Backend: Spring Boot  
Frontend: Angular


## Features
- Browse events & shows
- Book and manage tickets
- REST API 


## Run the Project

### Backend
```bash
mvn spring-boot:run
```
### Frontend
```bash
npm install 
npm install -g @angular/cli 
ng serve 
```
